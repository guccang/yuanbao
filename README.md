# 元宝成长乐园

面向 3–6 岁宝宝的每日数学与英语启蒙应用。每天自动生成一节约 8 分钟的课程，包含 3 个数学互动和 3 个英语互动。

## 功能

- 按宝宝年龄（3、4、5、6 岁）动态调整数字范围与题目难度
- 每天一节持续更新的确定性课程，数学与英语主题循环拓展
- 英语单词支持浏览器原生语音朗读
- 服务端持久化保存宝宝资料、课程断点与完成记录
- 连续打卡、星星、正确率、课程历史等成长数据
- 手机优先设计，支持安全区、大触控按钮和无障碍焦点
- 无第三方依赖，使用 Node.js 内置模块提供页面与数据服务

## 本地运行

启动应用服务：

```bash
node server.js
```

然后访问 `http://localhost:8887/`。

## 数据说明

宝宝资料和学习进度由服务端保存在 `data/yuanbao.json`。Docker Compose 部署时，该文件位于 `yuanbao-data` 持久卷中，重启或重建应用容器后仍会保留。升级后首次访问时，旧版浏览器 IndexedDB 中已有的数据会自动迁移到服务端。
