# 元宝成长乐园

面向 3–6 岁宝宝的每日数学与英语启蒙应用。每天自动生成一节约 8 分钟的课程，包含 3 个数学互动和 3 个英语互动。

## 功能

- 按宝宝年龄（3、4、5、6 岁）动态调整数字范围与题目难度
- 每天一节持续更新的确定性课程，数学与英语主题循环拓展
- 英语单词支持浏览器原生语音朗读
- IndexedDB 本地数据库保存宝宝资料、课程断点与完成记录
- 连续打卡、星星、正确率、课程历史等成长数据
- 手机优先设计，支持安全区、大触控按钮和无障碍焦点
- 无第三方依赖，可作为纯静态站点部署

## 本地运行

直接打开 `index.html`，或启动任意静态文件服务器：

```bash
node server.js
```

然后访问 `http://localhost:8882/`。

## 数据说明

宝宝资料和学习进度保存在当前浏览器的 IndexedDB 数据库 `yuanbao-learning` 中，不会上传到服务器。清理浏览器站点数据会同时清除学习记录。
