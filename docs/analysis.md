# 元宝成长乐园 — 项目功能分析与改进建议

## 一、项目概述

面向 3–6 岁宝宝的每日数学/物理/英语启蒙应用。后端使用 Node.js 纯内置模块（零外部依赖），前端采用 Vue 3 Composition API（CDN 加载），数据持久化为服务端 JSON 文件。单进程运行，无外部数据库依赖。

### P3 — 技术架构与工程化

#### 13. 缺少自动化测试
- **现状**: 零测试覆盖，课程模块确定性种子天然适合快照测试
- **建议**: 为课程生成模块添加单元测试，验证确定性输出；为 API 添加集成测试
- **价值**: 确保课程内容修改不破坏预期输出，建立回归防护
- **改动范围**: 新增 `test/` 目录 + `package.json` 测试脚本

#### 14. 前端代码模块化
- **现状**: `app.js` 约 750 行，包含所有 Vue 逻辑，维护成本高
- **建议**: 按功能拆分为 composables：`useAuth.js`、`useLesson.js`、`useProgress.js`、`useSchedule.js`
- **价值**: 提高可维护性，降低单文件认知负荷
- **改动范围**: 新建 `js/` 目录拆分 `app.js`

#### 15. ~~静态资源缺少 HTTP 缓存策略~~ ✅ 已实现
- 已对 CSS/JS 模块文件启用 `max-age=3600` 强缓存

#### 16. ~~缺少压缩传输~~ ✅ 已实现
- 已使用 Node.js 内置 `zlib` 模块，对大于 1KB 的文本静态资源启用 gzip 压缩

- **建议**: 增加主题数量（弹性、摩擦力、简单机械、颜色混合），5-6 岁增加因果推理题
- **价值**: 提升物理模块的丰富度和复玩性，避免内容疲劳
- **改动范围**: `modules/physics.js`

#### 18. ~~物理模块课程深度不足~~ ✅ 已修复
