# 元宝成长乐园 — 项目功能分析与改进建议

> 分析日期：2026-08-06 | 基于代码提交 `bcb6545`（沟通日志模块 + 今日故事任务）

## 一、项目概述

面向 3–6 岁宝宝的每日数学/物理/英语启蒙 + 情绪发展支持 + 沟通能力发展应用。后端使用 Node.js 纯内置模块（零外部依赖），前端采用 Vue 3 Composition API（CDN 加载），数据持久化为服务端 JSON 文件。单进程运行，无外部数据库依赖。

**项目规模**：4 个核心文件共约 6,200 行（server.js 约 870 + app.js 约 1,700 + index.html 约 950 + styles.css 约 2,700），3 个学科模块共约 1.1 万行。

## 三、改进建议（基于当前代码状态）

### P0 — 缺失的核心发展维度（已全部实现）

#### 1. 沟通能力模块（已实现）
- **现状**：✅ 已实现"今日故事任务"——每日生成 emoji 故事场景（25 种场景循环），引导儿童用语言描述，家长记录/评分。同时实现"沟通日志"——家长每周记录词汇量、句长、对话轮次、叙事能力、沟通主动性评分。
- **价值**：补齐三大发展维度之一，实现方法论中定义的沟通能力验证矩阵
- **参考**：`docs/developmental-framework.md §4.1`

#### 2. 持续专注模块（已实现）
- **现状**：✅ 已实现"专注力计时器"——在课程中实时显示专注时长，完成后展示"专注勋章"，自动采集专注力基线数据
- **价值**：补齐三大发展维度之一，采集专注力基线数据
- **参考**：`docs/developmental-framework.md §4.3`

### P1 — 功能增强

#### 3. 多宝宝支持
- **现状**：一个账户只能有一个宝宝资料
- **建议**：允许一个账户下创建多个宝宝（兄弟姐妹），各自独立进度和课程
- **价值**：多孩家庭共用账户，提升留存率和家庭覆盖
- **改动范围**：server.js profile 数据结构 → 数组 + app.js 宝宝切换 UI + 数据隔离
- **估算**：2-3 天

#### 4. 课程内容间隔复习
- **现状**：课程内容每日新主题，没有系统性的复习机制
- **建议**：基于艾宾浩斯遗忘曲线，在每周五/六插入复习日，回顾本周学过的单词和概念
- **价值**：提升学习效果，巩固长期记忆
- **改动范围**：modules/ 各模块增加 review 模式 + 课表系统支持复习标记
- **估算**：1-2 天

#### 5. 家长端数据看板增强
- **现状**：成长页面展示基础统计数据，但缺少趋势分析和对比
- **建议**：新增"学习趋势"视图——按周展示正确率趋势、学习时长趋势、各学科能力雷达图
- **价值**：帮助家长更直观地了解宝宝学习进展
- **改动范围**：app.js 新增 computed + index.html 新增 SVG 图表视图
- **估算**：1-2 天

#### 6. 情绪策略个性化推荐
- **现状**：策略推荐基于当前分区固定展示 3 种，没有考虑历史效果
- **建议**：根据历史策略使用数据（成功率、使用频率），为每个宝宝个性化排序推荐策略
- **价值**：提升策略有效性，让调节建议更精准
- **改动范围**：app.js 新增策略效果排序算法 + server.js 新增策略效果 API
- **估算**：1 天

### P2 — 用户体验

#### 7. 加载骨架屏
- **现状**：页面切换时有短暂白屏，无加载占位
- **建议**：为主要页面添加骨架屏（Skeleton Screen），提升感知加载速度
- **价值**：减少用户等待焦虑，提升流畅感
- **改动范围**：index.html 新增骨架屏模板 + styles.css 骨架屏动画
- **估算**：0.5 天

#### 8. 课程完成度预测
- **现状**：家长无法提前知道今天课程需要多长时间
- **建议**：在首页课程卡片上显示预计完成时间（基于历史数据计算）
- **价值**：帮助家长规划时间，提高课程完成率
- **改动范围**：app.js 新增预估时长 computed + index.html 展示
- **估算**：0.5 天

#### 9. 情绪自评提醒
- **现状**：情绪自评需要用户主动打开，容易忘记
- **建议**：在首页顶部增加未完成自评的温和提醒，或在课程开始前自动弹出
- **价值**：提高情绪数据采集率，让周报更准确
- **改动范围**：app.js 新增检测逻辑 + 首页提示条
- **估算**：0.5 天

#### 10. 课程内容音效与配音
- **现状**：课程仅有答题反馈音效，题目本身没有语音引导
- **建议**：为每个课程活动的标题和提示增加语音朗读（中文 TTS），让低龄宝宝也能独立使用
- **价值**：降低使用门槛，3 岁宝宝可以无需家长协助完成课程
- **改动范围**：app.js 新增中文 TTS 函数 + 课程页面增加自动朗读
- **估算**：1 天

### P3 — 技术架构与工程化

#### 11. 缺少自动化测试
- **现状**：零测试覆盖
- **建议**：为课程生成模块添加单元测试（确定性种子天然适合快照测试）；为 API 添加集成测试
- **价值**：确保课程内容修改不破坏预期输出，建立回归防护
- **改动范围**：新增 `test/` 目录 + `package.json` 测试脚本
- **估算**：2 天

#### 12. 前端代码模块化
- **现状**：app.js 约 1545 行，包含所有 Vue 逻辑，维护成本高
- **建议**：按功能拆分为 composables：`useAuth.js`、`useLesson.js`、`useProgress.js`、`useSchedule.js`、`useEmotion.js`
- **价值**：提高可维护性，降低单文件认知负荷
- **改动范围**：新建 `js/` 目录拆分 app.js
- **估算**：1-2 天（需注意 Vue 3 CDN 环境下的模块加载方式）

#### 13. 服务端数据迁移到 SQLite
- **现状**：使用 JSON 文件存储，大数据量下性能下降，不支持并发查询
- **建议**：迁移到 SQLite（better-sqlite3），保留 JSON 结构的灵活性同时获得数据库的查询能力
- **价值**：支持更复杂的查询（如趋势分析、跨用户统计），为多宝宝支持铺路
- **注意**：当前为零外部依赖，引入 SQLite 将打破这一特性
- **估算**：3-5 天

#### 14. 添加请求日志与监控
- **现状**：服务器仅输出 error 级别的日志，无请求日志、无性能监控
- **建议**：添加结构化请求日志（方法、路径、耗时、状态码），支持日志级别配置
- **价值**：方便排查问题，了解使用模式
- **改动范围**：server.js 新增 logger 中间件
- **估算**：0.5 天

#### 15. 打包工具引入
- **现状**：Vue 3 通过 CDN 加载，模块文件通过 `<script>` 标签加载
- **建议**：引入 Vite 构建工具，实现 ES Module 打包、HMR 开发体验、自动代码分割
- **价值**：提升开发效率，支持 npm 生态，更好的加载性能
- **改动范围**：新增 `package.json` + `vite.config.js`，重构模块加载方式
- **估算**：2-3 天
