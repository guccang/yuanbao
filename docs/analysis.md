# 元宝成长乐园 — 项目功能分析与改进建议

## 一、项目概述

面向 3–6 岁宝宝的每日数学/物理/英语启蒙应用。后端使用 Node.js 纯内置模块（零外部依赖），前端采用 Vue 3 Composition API（CDN 加载），数据持久化为服务端 JSON 文件。

## 三、改进建议（按优先级排序）

### P0 — 安全与稳定性

#### 1. PBKDF2 迭代次数不足
- **现状**: `server.js:37` 使用 10,000 次迭代
- **建议**: 提升至 310,000 次以上（OWASP 2023 推荐值）
- **风险**: 低迭代次数使暴力破解成本过低
- **改动范围**: `server.js` 第 37 行

#### 2. 缺少登录频率限制
- **现状**: 登录/注册接口无速率限制，可被暴力破解
- **建议**: 在内存中记录 IP 失败次数，连续失败 5 次后锁定 15 分钟
- **风险**: 账户密码可被在线穷举
- **改动范围**: `server.js`，新增速率限制中间件

#### 3. JSON 文件并发写入风险
- **现状**: `persistState()` 使用 Promise 链串行化写入，但 `loadState()` 仅在启动时读取一次
- **建议**: 多进程部署时需切换为 SQLite 或文件锁
- **风险**: 当前单进程模型下问题不大，但横向扩展时会出现数据丢失
- **改动范围**: `server.js` 持久化层

### P1 — 功能增强

#### 4. 多宝宝支持
- **现状**: 一个账户只能有一个宝宝资料
- **建议**: 允许一个账户下创建多个宝宝（兄弟姐妹），各自独立进度
- **价值**: 多孩家庭共用账户，提升留存率
- **改动范围**: `server.js` profile 结构 + `app.js` 宝宝切换 UI

#### 5. 错题本与复习模式
- **现状**: 答错的题目不会再次出现
- **建议**: 收集错题，每周自动生成一期复习课程，或在课程末尾插入 1-2 道错题
- **价值**: 强化薄弱知识点，符合教育螺旋上升理念
- **改动范围**: `modules/*.js` 课程生成逻辑 + `app.js` 复习路由

#### 6. 成就徽章系统
- **现状**: 仅有星星和连续天数统计
- **建议**: 增加成就徽章（首次完成课程、连续 7 天打卡、单科全对、累计 100 题等），在成长页面展示
- **价值**: 游戏化激励，提升学习动力
- **改动范围**: `app.js` 成就逻辑 + 新页面渲染

#### 7. 学习提醒（无外部依赖方案）
- **现状**: 无提醒机制
- **建议**: 利用 Notification API 在页面空闲时弹出"今天还没学习哦"提醒；或利用 Service Worker 实现离线推送
- **价值**: 提高每日活跃度
- **改动范围**: `app.js` 或新增 `sw.js`

#### 8. 课程内容扩展
- **现状**: 数学 10 个主题，物理 8 个主题（8 天循环），英语 64 个单词
- **建议**: 数学增加加减法混合运算、比较大小进阶、简单的应用题；物理增加电的初步认识、简单机械；英语增加字母学习、简单句型
- **价值**: 丰富课程内容，延长使用周期
- **改动范围**: `modules/*.js`

### P2 — 用户体验

#### 9. 离线支持（PWA）
- **现状**: 完全依赖网络连接
- **建议**: 添加 Service Worker 缓存静态资源（CSS/JS/HTML），实现基本离线可用；学习进度暂存到 localStorage，联网后同步
- **价值**: 弱网/断网场景下仍可学习
- **改动范围**: 新增 `sw.js` + `manifest.json` + `index.html` 引入

#### 10. 加载状态与骨架屏
- **现状**: API 请求期间仅有简单 loading 状态
- **建议**: 使用 CSS 骨架屏（已在 styles.css 中定义），让页面切换更流畅
- **价值**: 减少感知等待时间
- **改动范围**: `app.js` + `index.html` 模板

#### 11. 答题反馈强化
- **现状**: 答错仅有文字提示，无音效
- **建议**: 答错时播放柔和鼓励音效，避免挫败感
- **价值**: 符合幼儿教育"积极反馈"原则
- **改动范围**: `app.js` `playFeedbackSound` 调用

#### 12. 可打印练习册
- **现状**: 学习报告可导出 HTML，但不可直接打印为练习册
- **建议**: 新增 `/api/export/worksheets` 生成每日可打印 PDF 或 HTML 练习页
- **价值**: 家长打印出来让宝宝离线做
- **改动范围**: `server.js` 新增导出路由

### P3 — 技术架构

#### 13. Vue CDN 版本锁定
- **现状**: `index.html:11` 使用 `vue@3/dist/vue.global.prod.js`，未锁定具体版本
- **建议**: 锁定为 `vue@3.4/dist/vue.global.prod.js` 或使用具体版本号
- **风险**: Vue 大版本升级可能导致兼容性问题
- **改动范围**: `index.html` 第 11 行

#### 14. 前端代码模块化
- **现状**: `app.js` 707 行，包含所有 Vue 逻辑
- **建议**: 按功能拆分为 composables：`useAuth.js`、`useLesson.js`、`useProgress.js`、`useSchedule.js`
- **价值**: 提高可维护性，便于协作开发
- **改动范围**: 新建 `js/` 目录拆分 `app.js`

#### 15. 缺少自动化测试
- **现状**: 零测试覆盖
- **建议**: 为课程生成模块添加单元测试（确定性种子可输出固定结果，天然适合快照测试）
- **价值**: 确保课程内容修改不破坏预期输出
- **改动范围**: 新增 `test/` 目录 + `package.json` 测试脚本

#### 16. 物理模块课程深度不足
- **现状**: 物理 8 个主题固定循环，每个主题活动模式相似（认识→判断→比较）
- **建议**: 增加主题数量（如弹性、摩擦力、颜色混合），或为 5-6 岁增加因果推理题
- **价值**: 提升物理模块的丰富度和复玩性
- **改动范围**: `modules/physics.js`

## 四、总结

元宝成长乐园是一个功能完整、架构清晰、对幼儿教育有深入理解的应用。当前代码质量良好，零外部依赖、确定性课程生成、手机优先设计都是亮点。

核心改进方向：**安全性加固 → 游戏化激励 → 离线能力 → 内容扩展**。建议优先处理 P0 安全项，再根据用户反馈迭代 P1 功能增强。
